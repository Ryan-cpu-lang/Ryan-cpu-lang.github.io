What's New

v1.0.1：双击启动，零黑框

这是最新一版最主要的变化。以前双击启动器会跟着弹一个甚至几个 cmd 黑窗口，现在全没了。

🪟
现在只要双击 nuomiMC-GUI.vbs，窗口直接出来，屏幕上不会跟着黑框；想看下载日志时才用 start.bat download（那个框是有意留的）。
🖥️

双 exe 设计

nuomi.exe 保留控制台给 CLI / REPL；nuomiw.exe 是 GUI 子系统版。同一份二进制只改 PE 头 Subsystem（3→2），仅差 4 字节，入口代码完全不变。

🤫

静默子进程

proc.c 给 CreateProcess 加 CREATE_NO_WINDOW，curl / java 等后台进程不再弹窗，输出照旧走匿名管道回 GUI。

🔇

无控制台兜底

GUI 版没有 stdout，运行时自动把标准流接到 NUL、给子进程补有效 stdin 句柄，避免不同 CRT 的行为差异。

✅

实测验证

真·无控制台（DETACHED_PROCESS）下探针退出码 0、cmd/curl 子进程正常；console 版 12 个样例 + NUC 流水线 + 编译模式全部回归通过。

🧠
为什么不用 -mwindows 重编译？因为链接器切 GUI 子系统会改选 WinMainCRTStartup 入口，而 Nuomi 用的是标准 main()，会直接链接失败；而且一刀切会把 CLI 日志、REPL、编译模式全废掉。改 PE 头是 Python python.exe / pythonw.exe 同款做法。
Quick Start

三步开玩

不用装 Nuomi、不用配环境变量、不用编译 —— 所有东西都在 Release 压缩包里。

下载 7 个文件

从 v1.0.1 Release 把全部资产下载到同一个文件夹（路径别带奇怪符号）。

双击 nuomiMC-GUI.vbs

这是推荐入口，零黑框。等效命令是 start.bat gui；想看日志用 start.bat download。

加账户 → 启动游戏

在「账户」页添加微软 / LittleSkin / 离线账户，回到「启动游戏」页点一下即可。首次会下载 client.jar、依赖库与资源，稍等片刻。

☕
唯一前置条件：本机要装好 Java 并在 PATH 里（Minecraft 本体需要）。启动器会校验资源 SHA-1、自动解压 natives，其余都自动化。
Accounts

三种登录方式

账户存在 accounts.txt，一行一个，GUI 里一键切换；带 refresh token 的会自动静默续期。

🪪

微软正版 OAuth 2.0

标准设备码流（RFC 8628）：浏览器打开链接 → 粘贴设备码 → 授权，之后走 XSTS / Minecraft 服务换 token。支持 refresh token 静默续期，不用每次重登。

设备码流自动续期错误中文化
📖 看登录教程注册应用 ID ↗
🌸

LittleSkin Yggdrasil

走 /authenticate + /refresh，带 clientToken 静默续期。已修复密码含引号 / 反斜杠时的登录失败，以及 curl 读到陈旧响应的问题。实测登录通过 ✅

第三方皮肤站多角色切换门槛低
LittleSkin 官网 ↗
🎈

离线模式 Offline

只要填一个玩家名，不联网、不验证，立刻能进游戏。适合单机、局域网和先试试启动器好不好用。

零配置无需网络即开即用
⚠️
关于微软登录的门槛（说清楚免得踩坑）：启动器本身用的是标准 OAuth 2.0，但需要一个属于你自己的 Azure 应用 ID（公共 client_id 已被下架），还要提交 Mojang AppID 人工审核。而 Azure 免费账号现在要求手机号 + 实体信用卡验证，虚拟卡不收 —— 所以大多数人建议先用 LittleSkin 或 离线模式。完整流程见 教程。

Features

它能干什么

🖼️

自绘 GUI

启动 / 下载 / 账户三页，糯米语言的 13 个窗口原语画出来的真 Win32 窗口。

📡

离线 Piston API

解析版本清单，自动拉取 client.jar、依赖库、原生库与资源索引。

🔐

SHA-1 校验

每个资源下载后校验哈希，坏了就重下，不会因为一个坏包崩在游戏启动前。

⚡

并发下载

系统 curl --parallel 并发拉取 4000+ 资源文件，比内置 WinINet 串行快约 4 倍。

📦

自动解压 natives

自带 deflate 解压 zip / jar，原生库自动铺到实例目录，无需 zlib。

🔄

静默续期

微软 refresh_token / LittleSkin clientToken 都能后台换新，不用反复输密码。
