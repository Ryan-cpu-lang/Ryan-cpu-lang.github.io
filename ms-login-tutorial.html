微软正版账号登录教程

NuomiLauncher端到端 · 照着点就能登

本教程把「为什么不能直接登录 → 准备材料 → 在启动器里登录」一次性串清楚。最后更新 2026-11-05。

✅ 先说个好消息：LittleSkin 外置登录已经实测可用。
如果你只在自己的 LittleSkin 角色 / 离线单机之间玩，根本不用看下面这套微软流程。微软正版登录是给「要用微软账号进正版服务器」的人准备的，而且因为微软的政策，得自己动手注册一个应用（见下方「为什么」）。
为什么不能直接登录？ 早期各开源启动器共用的「公共 client_id」00000000402b5328 已被微软从目录里移除（2026-11-05 实测返回 AADSTS700016）。微软现在要求： ① 你自己的 Azure 应用（client_id） + ② 该应用通过 Mojang 的 AppID 审核 + ③（2024-06 起）个人账号要先有一个 Entra 目录（租户）。 这三步都是一次性配置，配好之后永久免维护。它们不是启动器的 bug，换任何启动器都一样。

⓪门槛零：拿到一个 Entra 目录（租户）

微软自 2024-06 起取消了「应用只关联个人账号、不属于任何目录」的注册方式。只用买 MC 的那个个人账号登录 Azure，点「新注册」会被直接拦下（在目录外部创建应用程序的功能已被弃用）。所以第一步是搞到一个真实租户。

A

最省事：你已经有工作 / 学校账号，或能被加进某个租户

让某个租户的管理员把你加为成员即可。免费、不用绑卡，最适合普通人。

B

通用解：注册 Azure 免费账号

打开 azure.microsoft.com/free 注册，会自动生成一个 Entra ID Free 租户并让你当全局管理员，应用注册永久免费。
⚠️ 微软会要「手机号 + 实体信用卡」做身份验证（临时预授权、不扣费，虚拟卡不行）。M365 开发人员计划 2026 年资格已收紧，纯个人通常显示「不符合资格」。

C

不推荐：External ID 30 天试用租户

不用绑卡，但只有 30 天、到期租户被删。而 Mojang 审核按周排队，client_id 会跟着失效，只适合临时验证。

📖 每一步的按钮位置与表单填写模板，看详细图文卡 azure-appid-guide.html 的 ⓪ 节。

①门槛一：注册 Azure 应用，拿到 client_id

前置：确认「当前目录」是 xxx.onmicrosoft.com 这种真实租户（不是纯 GUID 的隐式目录）。进入 Microsoft Entra ID → App registrations → New registration。

步操作注意
1Name 填 NuomiLauncher 之类不能含 Mojang / Minecraft / Microsoft / Live / Xbox / Discord / Hypixel，否则 Mojang 审核会打回
2Supported account types选 Accounts in any org directory + personal Microsoft accounts（含「个人 Microsoft 账户」那项）；选「Personal Microsoft accounts only」也行；不能选「仅此组织目录」
3Redirect URI 留空设备码流不需要回调，直接 Register
4进 Authentication 页 → Allow public client flows = Yes不做这步等于白注册，仍会报 unauthorized_client
5回 Overview 抄两个 UUIDApplication (client) ID（启动器要填的）和 Directory (tenant) ID（Mojang 审核必填）；别拿成 Object ID
📖 带每一步截图的图文：azure-appid-guide.html 的 ① 节。

②门槛二：提交 Mojang AppID 审核

新应用默认无权调 Minecraft Java API，login_with_xbox 会返回 403 Invalid app registration。去 aka.ms/mce-reviewappid 提交「AppID Review」表单，每周审一批，重复提交不会更快。

#字段填什么
1已阅读 EULAYes（指南）
2Contact Information注册 Azure 用的微软账号邮箱（官方会交叉核对）
3What type of requestNew AppID for Approval
4Application Name与 Azure 里一致，且不含禁用词
5Application IDOverview 里的 Application (client) ID，一次一个
6Tenant IDOverview 里的 Directory (tenant) ID，新应用必填
7Associated websitehttps://github.com/Ryan-cpu-lang/NuomiLauncher
8Justification说明开源非商业、完整走正版认证并验证游戏所有权（英文模板见下）
9Any other info留空 / N/A
Justification 英文模板（直接复制改名字）：
"Our open-source, non-commercial Minecraft launcher (NuomiLauncher) performs the
full Microsoft -> Xbox Live -> XSTS -> Minecraft Services authentication chain and
verifies game ownership before launching. It does not bypass, disable, or weaken
any authentication, ownership, or license check, and works normally with
online-mode servers. No game assets are redistributed; all downloads come from
Mojang's official endpoints or public mirrors."
合规底线：官方要求「应用必须验证用户拥有游戏、并在进入游戏前要求认证」，绕过正版验证的启动器一律不批。本启动器走的就是完整正版链路，这点没问题 👌
📖 审核表逐项说明 + 模板原文：azure-appid-guide.html 的 ② 节。

③在启动器里登录（核心）

材料齐了：你有 client_id，且 Mojang 审核已通过（没通过也能先登录，只是进正版服会卡 403，等批下来自动好）。下面是在 GUI 里实际操作。

第 1 步：打开启动器，进入账户页

双击 start.bat 启动 GUI → 侧栏点「账户登录」。账户页大概长这样：

NuomiLauncher · 账户登录
在这里粘贴 Application (client) ID
（用 LittleSkin 才填）
••••••••
已登录账户列表（点一下切换）：— 暂无 —

第 2 步：填 client_id 并保存

把 Overview 里抄的 Application (client) ID 粘进「微软 client_id」输入框，点「保存」。
也可以直接写文件 %USERPROFILE%\.nuomi-mc\ms_client_id.txt（纯一行 UUID，不要引号、不要空格）。只需填一次，之后不用再管。

💡 把 ID 发给助手（Pudding）也可以，助手会直接帮你写好并验证。

第 3 步：点「使用微软账号登录」

点主按钮「使用微软账号登录」后：

  • 启动器会自动打开你的默认浏览器，跳到微软登录页；
  • 同时把设备码自动复制到剪贴板（无需手动记）；
  • 启动器在后台按服务端节奏自动轮询，你不用盯着。

第 4 步：在浏览器里完成授权

在打开的微软登录页：用你的微软账号登录 → 到「输入设备码」那一步，Ctrl+V 粘贴启动器复制好的设备码 → 点「下一步 / 允许」。
（如果剪贴板没自动粘上，启动器的提示里也会显示设备码文本，手动抄也行。）

第 5 步：回到启动器，登录成功

授权完成后切回启动器，它会自动检测到并弹出「登录成功」。已登录账户列表里会出现你的微软账号，点一下即可选中。

第 6 步：启动游戏

回到主界面点「启动」，启动参数会自动带上 --clientId / --xuid / --userType msa / --accessToken，以你的正版账号进游戏。

第 7 步（以后）：续期不用重登

令牌会过期（改密码、异地登录等）。过期时点主按钮右边的「刷新」，启动器用存好的 refresh token 静默换新令牌，不开浏览器、不用重输密码。失败就重新点「使用微软账号登录」走一遍。

⚠️常见问题 / 排错

现象原因 / 处理
Invalid app registration / 403Mojang 审核还没通过，只能等（这段时间 LittleSkin / 离线照常玩）
unauthorized_client / AADSTS700016公共客户端流没开 Yes（回 ① 第 4 步），或还在用已被下架的公共 ID
账号类型不支持「支持的账户类型」选成了仅组织目录，回去改成含「个人 Microsoft 账户」
点「新注册」弹「在目录外部创建应用程序的功能已被弃用」2024-06 起个人账号无 Entra 租户，回 ⓪ 先建目录（换浏览器 / 重登无效）
AADSTS16000 ... not exist in tenant 'Microsoft Services'同上，Entra 管理中心对个人 MSA 拿不到目录令牌
设备码粘贴没反应剪贴板没复制成功，看启动器提示里的设备码文本手动抄
登录过期 / 会话无效点「刷新」；仍失败就重新点「使用微软账号登录」
审核被打回多半应用名含禁用词，或 Justification 没写清「验证游戏所有权」
🔑 一个易混点：你自己的 Directory (tenant) ID 只给 Mojang 审核表单用，不要填进启动器。启动器代码用的是固定的 consumers 端点，把 tenant ID 填进去反而会错。
