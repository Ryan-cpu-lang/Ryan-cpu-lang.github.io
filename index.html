About

这是什么

Nuomi 是一门参考 Scheme / Clojure 的 Lisp 风格语言，用纯 C 实现 （树遍历解释器 + 引用计数 GC），零外部依赖。它内置窗口 / GUI、HTTP、进程、 JSON、文件、SHA-1 校验与解压等一整套应用层原语；配套 NUC 可执行格式 与编译后端， 能把 Nuomi 子集直编成 novus-os 的原生 x86_64 机器码。

一句话：写起来像 Lisp，跑起来是原生码 —— 既适合写小工具、游戏和启动器， 也能作为 novus-os 的用户态语言模块。

🆕
最新进展（2026-11-06）：Nuomi 新增 nuomiw.exe（GUI 子系统解释器）， 配合 CREATE_NO_WINDOW 静默子进程，彻底解决了 Windows 下启动 GUI 时弹 cmd 黑框的问题。 CLI 用的 nuomi.exe 保持不变，两套并存、互不干扰。
Features

核心特性

从语法到系统调用，一套语言覆盖应用层开发。带 NEW 的是最近落地的能力。

🧬

Lisp 语法

S 表达式、闭包、高阶函数，以及 let / let* / letrec 三套局部作用域。

⚙️

纯 C 实现

零依赖，单文件 nuomi.exe 自带全部功能与 NUC 工具链（用 nuomi nuc 调用）。

🪟

窗口 / GUI

13 个窗口原语：Windows 上是真 Win32 窗口，novus 上走 Novus-WM IPC，脚本不变。

🌐

HTTP / 进程

拉取版本清单、并发下载资源、spawn 子进程抓日志 —— 启动器就靠这些。

🔐

SHA-1 / unzip

文件完整性校验、解压 zip·jar，自带 deflate，无需 zlib。

📦

NUC 工具链

novus-os 原生格式读写 / 校验 / dump / 编译，emit-demo → validate → run 全通。

🚀

Route A 编译

Nuomi 子集 → x86_64 → .nuc，产物与官方 DEMO.NUC 格式逐字段对齐。

💾

JSON / 文件

读懂版本清单、管理实例目录；软错误返回 nil/false/-1，不中止程序。

NEW
🖥️

双 exe · 零黑框

nuomi.exe 留给 CLI/REPL，nuomiw.exe 是 GUI 子系统版。同一份二进制只改 PE 头 4 字节，入口不变。

NEW
🤫

静默子进程

CreateProcess 加 CREATE_NO_WINDOW，curl / java 后台跑不弹窗，输出仍走匿名管道回 GUI。

NEW
⚡

并发下载 + 校验

系统 curl --parallel 并发拉取 4000+ 资源，逐文件 SHA-1 校验，比内置 WinINet 快约 4 倍。

🔤

中文 / UTF-8

字符串 \r 转义、CreateWindowExW 中文标题栏、控制台 UTF-8 输出，中文路径与界面不乱码。

下面都是真实可运行的 Nuomi 片段（注意：颜色用十进制，Nuomi 不支持 0x 字面量）。点标签切换，右上角可一键复制。

启动器命令
repl

nuomi> (+ 1 2 3)
=> 6
nuomi> (define (sq x) (* x x))
=> <fn sq>
nuomi> (sq 9)
=> 81

;; 给每个元素求平方
(define (sq x) (* x x))
(map sq [1 2 3 4])
;; => [1 4 9 16]

;; 过滤出偶数
(filter (lambda (n) (= 0 (% n 2))) [1 2 3 4 5 6])
;; => [2 4 6]

;; 局部作用域：并行绑定，不污染全局
(let ((a 1) (b 2))
  (+ a b))

;; 颜色用十进制：rgb(r,g,b) = r*65536 + g*256 + b
(define (rgb r g b) (+ (* r 65536) (* g 256) b))

(define ui (window-create 200 150 480 440 "Nuomi 窗口"))
(window-fill ui 0 0 480 440 (rgb 20 22 26))      ;; 背景
(window-text ui 40 66 2 "你好，糯米!" (rgb 255 255 255))
(window-invalidate ui)

;; 主循环里非阻塞取键：'up 'down 'left 'right 'esc ...
(window-event)

;; 宿主机：把 Nuomi 子集编译成 novus-os 原生可执行格式
nuomi -c program.nuomi -o program.nuc

;; NUC 工具链：生成 / 校验 / dump / 真机执行
nuomi nuc emit-demo demo.nuc
nuomi nuc validate demo.nuc
nuomi nuc run demo.nuc        ;; entry returned: 42 (0x2A)

;; NuomiLauncher —— 全部逻辑都在 .nuomi 脚本里
nuomiMC-GUI.vbs        ;; ★ 双击这个：零黑框开 GUI
start.bat gui          ;; 等价命令行入口
start.bat dry          ;; 只规划，打印 java 启动命令
start.bat download     ;; 下载 client.jar / 依赖库 / 原生库 / 资源包
start.bat launch       ;; 下载并启动 Minecraft

;; 想看日志时用 console 版，那个黑框是有意留的
nuomi.exe launcher.nuomi
Download

安装与下载

三个平台都能跑；Windows 下载走国内加速镜像（ghproxy 系），直连可用、无需访问 GitHub。

🪟 Windows

nuomi.exe 单一文件（v0.3.1，约 630 KB），已含全部功能与 NUC 工具链。装完 cmd 直接敲 nuomi；以后 nuomi update 一条命令自升级。

⬇ 下载 nuomi.exe（镜像加速）
备用镜像：gh-proxy.com · ghproxy.net
另有 nucutil.exe · v0.3.1 Release 页 ↗

🐧 Linux

需要 gcc + make。克隆仓库后 make 产出单一 nuomi，make test 跑全套样例与 NUC 流水线。国内克隆可加镜像前缀。

📋 复制克隆命令
或 直接查看仓库 ↗

🖥️ novus-os

直接拷 dist/novus/ 下已编译好的 .nuc 进 novus-os，用 shell exec 执行；自编程序用 nuomi -c 编译。

novus-os

作为 novus-os 模块

Nuomi 是 novus-os 的用户态语言模块（作者也是 novus-os 的作者之一）。 Route A 后端把 Nuomi 编译成 x86_64 原生码塞进 .nuc，直接跑在 novus 内核上； 文件操作走 syscall、窗口走 Novus-WM IPC，脚本接口不变。 目标作为官方仓库的 user/nuomi/ + tools/nucutil/ 模块合入。
